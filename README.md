# Six Factor Stock Analysis Platform

A comprehensive stock analysis platform based on a six-factor framework for evaluating stocks.

## Project Structure
```
/six-factor-stock-analysis
├── frontend/         # React frontend application
├── backend/         # Express.js backend server
└── README.md
```

## Features
- Stock analysis using six-factor framework
- Real-time data from Alpha Vantage
- Interactive charts and visualizations
- User authentication
- Saved analyses
